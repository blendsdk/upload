# Upload System Requirements

The feature set defines the greenfield upload package family for BlendSDK v5.

| RD                                         | Scope                                              |
| ------------------------------------------ | -------------------------------------------------- |
| [RD-01](RD-01-repository-and-toolchain.md) | Repository, TypeScript 7, Vite, Turbo and lockstep |
| [RD-02](RD-02-protocol-and-client.md)      | Shared protocol, validation and client engine      |
| [RD-03](RD-03-server-pipeline.md)          | WebAFX plugin, tus, storage and finalization       |
| [RD-04](RD-04-fluentui-component.md)       | React 19 / Fluent UI v9 component                  |
| [RD-05](RD-05-security-and-operations.md)  | Security, persistence and cleanup                  |
| [RD-06](RD-06-docs-and-release.md)         | VitePress documentation and release workflow       |

Cross-feature references are not used; every RD is scoped to `upload-system`.
