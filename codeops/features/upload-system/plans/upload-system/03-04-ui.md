# UI Design

The component follows the Fluent UI v9 anatomy:

| File                            | Responsibility                                    |
| ------------------------------- | ------------------------------------------------- |
| `FileUpload.tsx`                | `forwardRef` shell                                |
| `FileUpload.types.ts`           | Public props, strings, state and action contracts |
| `useFileUpload.ts`              | Manager binding, dropzone, callbacks and actions  |
| `renderFileUpload.tsx`          | Pure render                                       |
| `useFileUploadStyles.styles.ts` | Griffel styles and tokens                         |
| `strings.ts`                    | English defaults and override resolution          |
| `index.ts`                      | Public exports                                    |

The component is controlled at the queue level: the host supplies the client and purpose, optionally supplies an app-level manager, and receives ready items through `onUploaded`. It does not own dialogs, forms or commit decisions.

The dropzone is a keyboard button. The native input remains available for mobile pickers. File rows expose labelled actions, progress and status text. Error and success messages use MessageBar; processing uses Spinner. Styles use tokens and a narrow-width media query.
